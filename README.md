# Gency School Management System

A React + Vite school management workspace. The first development phase uses browser local storage for demo data; a real backend (such as Supabase) will be integrated later.

## Run locally
```bash
npm install
npm run dev
```

## Stack
- React + Vite
- Tailwind CSS
- React Router
- Recharts
- Lucide React

## Current phase
Project foundation and responsive admin dashboard. Demo data is stored in the current browser only. Do not use real student or financial information in this demo.
